# ADR 0007: 阴影先 CSM 光栅；DXR 可开关示范

- 状态: Accepted
- 日期: 2026-08-12
- 关联: CH10、CH19, PLAN M5/M8/M25

## 背景

全量光追阴影成本高且依赖硬件；通用路径需要可靠光栅阴影。

## 决策

1. **方向光主路径：CSM（光栅）**；点/聚光阴影走 Atlas（P0）。  
2. **DXR** 为可开关示范/增强；无 DXR 或关闭时必须降级到光栅。  
3. Vulkan RT 对齐放 **M25**（ADR 0023）；能力差见 L0/L1/L2。

## 后果

- 优点：最低配置可玩/可验；先进特性可选。  
- 代价：双路径维护；内容需知 Feature。
