# ADR 0005: 材质 Keyword 变体与 PSO 缓存

- 状态: Accepted
- 日期: 2026-08-12
- 关联: CH08, engine/material

## 背景

每材质手写全套 PSO 不可维护；运行时无限变体会卡顿与爆炸。

## 决策

1. 材质用 **Keyword / 宏变体** 驱动 Shader 排列；PSO 缓存去重。  
2. 热路径避免每帧新建 PSO；变体集合可预热或异步编译（后续里程碑打磨）。  
3. 不做材质节点图可视化编辑器（ADR 0025）。

## 后果

- 优点：扩展着色模型可插拔。  
- 代价：变体组合需纪律与工具支持（shader_compile）。
