# ADR 0014: 通用渲染补强分 P0/P1

- 状态: Accepted
- 日期: 2026-08-12
- 关联: CH22–CH28, PLAN M10–M14

## 背景

基础段（M1–M9）已覆盖垂直渲染与媒体；要对齐「通用 3D 渲染引擎」仍缺多灯阴影、TAA、AO、LOD、流式、遮挡等基础能力，以及 SSR/曝光等标配。

## 决策

1. 将补强分为 **P0（刚需）** 与 **P1（标配）**，对应里程碑 M10–M14。  
2. **P0 完成前**，不宣称「通用渲染引擎」验收通过。  
3. 其它图形后端（Metal / D3D11 实装等）明确不做；**Vulkan** 按 ADR 0020 在 **M17/M18** 落地（非「无限后置」）。动态 GI / 地形等按 ADR 0023 在 **M20–M25**，不在本 ADR 的 P0/P1 范围内。

## 后果

- 优点：验收边界清晰，避免与基础段纠缠。  
- 代价：总周期拉长，必须分段交付。

## 学习提示

1. 先搞懂 CSM/视锥，再学 Atlas 与遮挡。  
2. TAA 与超分共享 Jitter/运动向量直觉。
