# ADR 0029: 物理加深边界（薄 SoftBody / Cloth）

- 状态: Accepted
- 日期: 2026-08-14
- 关联: ADR 0015、KNOWN_GAPS **C22**、看板 **W-phys-soft**

## 背景

ADR 0015 将布料/软体标为后置；M12 刚体路径已稳定。主线板梳理需要明确：哪些可进 `engine/`，哪些仍属范围外。

## 决策

1. **允许**经 `IPhysicsWorld` 增加**薄** SoftBody / Cloth（创建、与刚体共用 `Step`、读回顶点或挂渲染网格）；实现放 Jolt 适配层，Sample **不直链** Jolt。  
2. Builtin 物理世界对软体能力 **SKIP**（Feature / 文档标明）。  
3. **不允许**进 `engine/`：服装 **DCC 编辑**、裁片缝线、撕裂资产流产品化；完整载具轮胎与破坏专用求解器产品化。  
   **Mega-W10 / ADR 0037 修订**：允许 **演示级** 披风/裙摆 SoftBody 挂接 + possess 走跳（非服装产品管线）。  
4. 验收以 Demo + DebugDraw + 刚体路径不回归为准；不做服装级仿真质量承诺。

## 后果

- 优点：与现有物理抽象一致；可换 PhysX 适配而不改业务。  
- 代价：抽象需为软体读回留最小面；文档须持续区分 C22 vs 服装管线。

## 学习提示

1. 软体权威在物理世界；渲染网格只采样顶点。  
2. 无 Jolt 或未开 Feature 时调用应失败或空操作，不得硬崩。
