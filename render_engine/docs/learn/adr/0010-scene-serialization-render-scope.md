# ADR 0010: 场景序列化范围（渲染向）

- 状态: Accepted
- 日期: 2026-08-12
- 关联: CH20, engine/scene, ADR 0025

## 背景

完整关卡编辑器超出引擎范围，但 Sandbox 与发版需要可存读的场景/清单。

## 决策

1. 序列化服务 **渲染向场景**（节点、相机、材质引用、灯光等），非全能编辑器工程格式。  
2. 内容生产靠外部 DCC + 最小工具链（ADR 0025）；引擎提供导入/清单/序列化。  
3. 不做可视化关卡编辑器。

## 后果

- 优点：范围可控；与 cook/清单协同。  
- 代价：无点选式编辑体验。
