# ADR 0009: 学习轨与产品轨双轨共存

- 状态: Accepted
- 日期: 2026-08-12
- 关联: CH00, docs/learn/*

## 背景

仓库同时承担「可交付轻量 3D 引擎」与「可学习如何造引擎」两种目标。若只保留产品 Sandbox，学习者会被完整功能淹没；若拆成两套互不相干的代码，维护成本翻倍。

## 决策

采用 **双轨共存、单套引擎核心**：

- **产品轨**：`engine/` + `samples/Sandbox` + PLAN 里程碑。  
- **学习轨**：`docs/learn/*` + `samples/learn/NN_*` + 教学开关（`learn.*`）。  

学习 Sample 裁剪场景与开启教学开关；不复制第二套 D3D12 后端。

## 备选方案

1. 仅产品引擎，另写博客教程 —— 文档易与代码脱节。  
2. 独立 `learning_engine` 仓库 —— 分叉后难以合并架构演进。  
3. 同一可执行文件用关卡解锁功能 —— 实现复杂，干扰产品验收。

## 后果

- 优点：一份实现、两套入口；ADR/章节可解释架构动机。  
- 代价：需约束 Sample 规范；文档与里程碑要双线更新。  

## 学习提示

1. 先走 learn 阶梯，再打开 Sandbox。  
2. 看到 `learn.*` 开关变慢是正常的。  
3. 选修章（DLSS/DXR 等）不要插队到三角/RHI 之前。
