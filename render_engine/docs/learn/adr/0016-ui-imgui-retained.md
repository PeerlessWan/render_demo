# ADR 0016: UI 双轨——ImGui 调试 + 保留模式运行时

- 状态: Accepted
- 日期: 2026-08-12
- 关联: CH29, engine/ui, M8/M15

## 背景

通用渲染引擎需要调试面板与运行时 HUD/菜单。纯 ImGui 可快速出工具 UI，但正式菜单/HUD 更适合保留模式文档流；完整可视化 UI 编辑器成本接近「又一个编辑器」。

## 决策

1. **Immediate（Dear ImGui）**：控制台、Profiler、质量档/调试面板；M8 雏形，M15 打磨。  
2. **Retained（推荐 RmlUi 或薄自研）**：主菜单、HUD、文本与基础控件。  
3. 统一经 **UI Pass** 在 FrameGraph 中于 3D/后处理之后绘制。  
4. 输入经 `WantCapture` 与 ActionMap 分流。  
5. **不做** 独立可视化 UI 编辑器。

## 后果

- 优点：工具效率与运行时 UI 质量兼顾；范围可控。  
- 代价：两套路数需文档区分；布局资源需外部或手写。

## 学习提示

1. 先搞清「谁吃输入」再谈控件。  
2. UI 分辨率与渲染分辨率、DPI 是三件事。
