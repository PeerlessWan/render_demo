# 基础速查：数学、坐标、HLSL

学习渲染引擎前的最小工具箱。不替代教材，只避免「卡在约定上」。

## 1. 本引擎约定（实现时锁定，此处先定稿）

| 项 | 约定 |
|---|---|
| 矩阵约定 | **列主序**，向量为列向量；变换为 `P * V * M * v`（实现若调整，以代码与本章更新为准） |
| 世界空间 | Y 向上（常见右手或 DX 常用布局以实现锁定；Sample 中画轴调试） |
| 裁剪空间 | D3D 风格 NDC：`z ∈ [0,1]` |
| 纹理 | UV 原点在左上；注意与部分 DCC 的 V 翻转 |
| 颜色 | 着色在 **线性空间**；输入 sRGB 纹理由采样自动转线性；最终经 Tonemap 再进 sRGB 显示 |

> 实现 M1/M2 时若有调整，必须同步改本节，避免文档与代码漂移。

## 2. 常用矩阵直觉

| 矩阵 | 作用 |
|---|---|
| Model / LocalToWorld | 物体 → 世界 |
| View | 世界 → 相机 |
| Projection | 相机 → 裁剪 |
| NormalMatrix | 通常取模型矩阵左上 3x3 的逆转置（均匀缩放可简化） |

## 3. 常量缓冲对齐（HLSL `cbuffer`）

- `float4` 按 16 字节对齐打包。  
- 独自一个 `float` 常会「占满到下一个 16 字节槽」——怀疑错乱时先查打包。  
- CPU 结构体建议显式 padding，或用引擎提供的反射/打包工具。

## 4. HLSL 最小陪练路径（建议与 Sample 同步）

1. 纯色三角（CH02）  
2. 顶点色 / UV 可视化（CH03）  
3. Lambert N·L（CH04）  
4. Blinn-Phong（可选作业）  
5. Cook-Torrance PBR + IBL（CH09）  

每一步只改 PS（或 VS 变换），便于对比。

## 5. 调试颜色约定（建议）

|---|---|

| 级联染色 | 不同 CSM cascade |
