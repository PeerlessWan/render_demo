# Suburb town block (CC0)

Assembled from **Kenney City Kit (Suburban) 2.0** — real modular game assets
(buildings, trees, fences, paths), not a single prop.

| Path | Notes |
|---|---|
| `models/*.glb` | Curated subset (~1 MB) |
| `models/Textures/colormap.png` | Shared Kenney colormap |
| `download_suburb_scene.ps1` | Re-fetch full pack / refresh subset |
| `LICENSE.txt` | CC0 |

## Sandbox

Loaded at startup into mesh slot 6 (`mesh_id=suburb`). Camera starts overlooking the block.

Upstream: https://kenney.nl/assets/city-kit-suburban  
Mirror zip used by script: OpenGameArt `kenney_city-kit-suburban_2.0.zip`
