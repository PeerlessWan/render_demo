# editor 功能清单

> `规划` = 目标能力；实现见 [PLAN.md](PLAN.md)。一期做「能摆、能改、能存、能再加载」。

## 1. 视口与场景

| ID | 功能 | 说明 | 状态 |
|---|---|---|---|
| EDVP01 | 3D/2D 视口 | 经引擎 Present；质量档可降以保编辑流畅 | 规划 |
| EDVP02 | 编辑相机 | 飞行/轨道；与游戏相机分离 | 规划 |
| EDVP03 | 网格/Gizmo | 平移旋转缩放；吸附可选 | 规划 |
| EDVP04 | 选中高亮 | 轮廓或 DebugDraw；复用引擎拣选能力（对齐 M20） | 规划 |
| EDVP05 | 多视口 | 后置 | 候选 |

## 2. 层级与属性

| ID | 功能 | 说明 | 状态 |
|---|---|---|---|
| EDHI01 | 场景树 | 显隐、重父级、搜索 | 规划 |
| EDHI02 | 检视器 | 变换、灯光、相机、材质引用（AssetId） | 规划 |
| EDHI03 | 创建/删除节点 | 基本类型（空节点、网格实例、灯、精灵…） | 规划 |
| EDHI04 | 脚本组件字段 | 若链 game_kit：显示公开字段、脚本路径 | 规划 |
| EDHI05 | Prefab 编辑 | 实例覆盖 vs 源；一期可只「放置实例」 | 规划 |

## 3. 内容与 IO

| ID | 功能 | 说明 | 状态 |
|---|---|---|---|
| EDIO01 | 打开/保存场景 | 与引擎序列化格式一致 | 规划 |
| EDIO02 | 内容浏览器 | 按 Manifest/AssetId 浏览 | 规划 |
| EDIO03 | 拖拽放置 | 网格/Prefab 拖入视口 | 规划 |
| EDIO04 | 调用 cook | 保存后可选跑清单刷新 | 规划 |
| EDIO05 | Undo/Redo | 属性与变换栈 | 规划 |

## 4. 播放与调试

| ID | 功能 | 说明 | 状态 |
|---|---|---|---|
| EDPL01 | Play-in-Editor | 进入/退出；快照策略 | 规划 |
| EDPL02 | 暂停 | 逻辑暂停 | 规划 |
| EDPL03 | 引擎调试叠加 | 可开 Profiler/碰撞/像素网格等 | 规划 |

## 5. 明确不做（一期 / 默认）

| 项 | 说明 |
|---|---|
| 材质节点图可视化 | 范围外（G17） |
| UMG 级 UI 编辑器 | 范围外 |
| 动画状态机/曲线编辑器 | 后置 |
| 地形雕刻完整套件 | 引擎 M23 基础后另议 |
| FBX/USD 一站式导入器 | 外部转换 + glTF |
| 内置完整 DCC | 不替代 Blender 等 |

轻量 CLI 工具（仅校验/浏览）见引擎 **C20**，可先于本编辑器交付。
